# GliderAnalysis

[![Build Status](https://github.com/dankelley/GliderAnalysis.jl/actions/workflows/CI.yml/badge.svg?branch=main)](https://github.com/dankelley/GliderAnalysis.jl/actions/workflows/CI.yml?query=branch%3Amain)

GliderAnalysis is a Julia package for working with ocean glider data. It is not
suitable for general usage at this stage. Indeed, it may never be suitable; at
the moment, it's just a convenient way to package code for an analysis of some
particular datasets.
